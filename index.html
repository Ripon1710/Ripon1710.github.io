プロジェクトProjects

UI: ベンガル語UI: Bengali

Club Hisab

Webアプリ ・ 個人開発（実際のクライアント）Web App · Solo Build for a Real Client

課題Problem
バングラデシュの農村にある社会活動クラブ（会員30名以上）では、誰がいくら納め、資金が何に使われたかを会員が確認する手段がありませんでした。 A social-work club of 30+ members in a Bangladeshi village had no way for members to see who paid what or where the money went.
担当My Role
外部の開発者として、企画・UI設計・フロントエンド・バックエンド・デプロイまで一人で担当。現在は管理者として運用も行っています。 As an outside developer, I designed and built the entire app solo — planning, UI, front end, back end, and deployment — and now run it as admin.
成果Result
段階的に導入中で、現在10名以上の会員が利用しています。入金・支出・残高を全員がリアルタイムで確認できるようになりました。サーバーレス構成により、運用コストは0円です。 Rolling out in stages, with 10+ members actively using it. Every member can now see contributions, spending, and balance in real time. Serverless architecture keeps running costs at zero.

主な機能Key Features

  • 会員用PINログインと管理者ログインを分離Member PIN login with a separate admin login
  • Firestore Security Rulesでアクセス権限を制御（テスト102件）Access control enforced with Firestore Security Rules (102 tests)
  • bKash・Nagadの入金を取引IDで申請し、管理者の承認後に反映（重複IDは自動ブロック）bKash/Nagad payments submitted with a transaction ID and counted only after admin approval (duplicate IDs blocked)
  • カテゴリ別・イベント別の支出管理Expense tracking by category and event
  • 残高と納入状況が一目で分かるダッシュボード、公開アクティビティログ、お知らせ掲示板Dashboard showing balance and who has or hasn't paid, plus a public activity log and notice board
  • PWA対応（ホーム画面に追加可能）、Cloudflare Workerによるプッシュ通知Installable PWA with push notifications via a Cloudflare Worker
  • HTML
  • CSS
  • JavaScript
  • PWA
  • Firebase (Firestore / Auth / Hosting / FCM)
  • Cloudflare Workers
  • Serverless
